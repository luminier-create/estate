확정된 스펙은 `03-DATA-SOURCES.md`, 여기는 그 스펙이 왜 그런지와 변화 추적.

- 모든 항목에 **확신도 라벨**, **출처 링크**, **확인일** 을 붙인다
- 라벨: `[확인됨]` 공식 문서 확인 / `[검증필요]` 2차 출처만 / `[추정]` 계산·추론

- 사실이 바뀌면 이전 값을 지우지 말고 **변경 이력**에 남긴다 — 왜 바꿨는지가 중요하다

## 1. 외부 API 정책

### 1.1 카카오맵 API — 2026-07-21 정책 변경

`[확인됨]` 확인일 2026-09-09
출처: [카카오 데브톡 공지](https://devtalk.kakao.com/t/api-notice-on-new-kakao-map-api-features-and-free-quota-policy/150222)

- 신청·심사 없이 앱 관리 페이지에서 **카카오맵 API 활성화 + 비즈월렛 연결**로 이용
- **개발자 계정 기준 첫 번째로 활성화한 앱에만 무료 쿼터 제공**
- 두 번째 앱부터, 또는 무료 쿼터 초과 시 **사용량 기반 과금**
- 신규 API 4종 추가: 대중교통 경로, 도보 경로, 자전거 경로, 정적 지도

**우리 앱에 대한 함의**: 대중교통 경로 API가 새로 생겨 **ODsay 대체 가능성**이 열렸다.
ODsay 무료 티어가 6개월 만료이므로 대안으로 검토할 가치가 있다.
Provider 인터페이스 뒤에 있어 교체 비용은 작다.

`[검증필요]` 로컬 API 무료 한도의 정확한 수치는 공식 문서로 확인하지 못했다
(작업 환경에서 `developers.kakao.com` 접근이 차단됨). 발급 시 콘솔에서 확인할 것.

### 1.2 ODsay — Basic 은 6개월 한정

`[확인됨]` 확인일 2026-09-09
출처: [ODsay LAB 운영정책](https://lab.odsay.com/doc/totalPolicy), [FAQ](https://lab.odsay.com/community/faq)

| 티어 | 대상 | 한도 | 비용 |
|---|---|---|---|
| Basic | 개인·학생·5인 이하 스타트업 | 1,000회/일 | **6개월 무료** |
| Standard | — | 100,000회/일 | 유료(문의) |
| Premium | — | 100,000회 초과 | 유료(문의) |

초당 호출 제한도 있으나 수치는 비공개.

**우리 앱에 대한 함의**: 가장 먼저 유료화되는 병목이다. 기본 쿼터 상한을 800으로
보수적으로 잡은 이유. 6개월 시점에 카카오맵 대중교통 API 로의 전환을 검토해야 한다.

## 2. 비용 시뮬레이션

`[추정]` 계산일 2026-09-09
가정: 일 활성 사용자 50명 × 각 3개 단지 분석 = 150 분석/일

| 서비스 | 일 소비 (캐시 히트 제외) | 한도 대비 |
|---|---|---|
| 국토부 | ~1,200회 | 여유 |
| Firestore 쓰기 | ~6,000건 | 여유 |
| 카카오 | ~1,500회 | 여유 |
| **ODsay** | ~900회 | **한도 근접** |

분석 1회당 외부 호출: 카카오 POI 9종 + 지오코딩 1, ODsay 경로 5~6 + 정류장 1,
국토부 24개월. 국토부는 법정동 단위 캐시라 같은 지역 단지끼리 공유된다.

**결론**: Vercel + Firebase Spark 조합이면 6개월간 0원. 병목은 ODsay 하나.

## 3. 도메인 지식

### 3.1 재건축 연한과 가격 반영

`[검증필요]` 확인일 2026-09-09

도시정비법상 재건축 연한은 준공 후 30년(서울시 기준). 30년 도달 시점에
안전진단·정비구역 지정 기대가 가격에 선반영되는 경향이 있어, 노후도 점수를
단조 감소로 두면 현실과 어긋난다. → `AGE` 축을 U자 곡선으로 설계한 근거.

반등폭은 68점으로 제한했다. 실제 정비사업 진행 단계는 `DEVELOPMENT` 축이
확실성 계수로 평가하므로, 여기서 크게 반등시키면 이중 계상이 된다.

### 3.2 실거래 데이터의 한계

`[확인됨]` 확인일 2026-09-09

- 신고 기한 30일 → 당월 데이터는 항상 불완전
- 직거래·특수관계 거래가 섞여 극단값이 나온다 → IQR 1.5배 이상치 제거 필요
- 계약 해제 건(`cdealType === 'O'`)이 응답에 포함된다 → 반드시 제외

### 3.3 보행 속도 기준

`[검증필요]` 확인일 2026-09-09

성인 평균 보행속도 4.0km/h(=67m/min)를 채택했다. 직선거리를 실보행거리로 바꾸는
우회계수는 도심 격자 도로망 기준 1.25 로 근사했다. 두 값 모두 스코어링과 지도
표시에 공통으로 쓰이므로 바꾸면 양쪽이 함께 움직인다.
